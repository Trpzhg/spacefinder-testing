# SpaceFinder

Учебный проект веб-приложения для поиска и бронирования коворкингов в Санкт-Петербурге.

## Основные возможности
- поиск рабочих пространств по району и станции метро;
- фильтрация по стоимости, графику и доступному оборудованию;
- просмотр карточек коворкингов;
- отправка запроса на бронирование;
- хранение тестовой документации и истории изменений.

## Структура ветвей
- `main` — стабильные материалы проекта;
- `catalog-search` — каталог и фильтрация;
- `booking` — бронирование и пользовательские сценарии.
